## About

Data Engineer by day, SaaS creator and independent security researcher the rest of the time. Founder of [Enterprise Hare LLC](https://www.enterprisehare.com), an offensive security lab that also ships software.

## What I build

- Data engineering: ETL pipelines, data modeling, orchestration, analytics
- Backend services: Python, SQL, APIs, cloud infrastructure
- SaaS products and developer tooling
- Cloud: AWS and Azure

## What I break

Independent vulnerability research across web applications, cloud platforms, and open-source projects. Findings are reported through coordinated disclosure and published only after a fix ships.

Credited by Apple in the Safari 26.5.2 security release and by the European Space Agency in [GHSA-g49g-f3f6-g578](https://github.com/esa/asn1scc/security/advisories/GHSA-g49g-f3f6-g578).
